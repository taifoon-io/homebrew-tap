# taifoon-io/homebrew-tap

Homebrew formulae of Taifoon.

```
brew install taifoon-io/tap/taifoon
taifoon --version
```

`taifoon` is the Taifoon coordination layer in the terminal ([source](https://github.com/taifoon-io/cli), [npm](https://www.npmjs.com/package/@taifoon/cli)).
The formula installs the standalone binary from the [taifoon-io/cli releases](https://github.com/taifoon-io/cli/releases), checked
against the SHA-256 recorded here; each release's `SHA256SUMS` is signed with sigstore by that repository's release workflow.
